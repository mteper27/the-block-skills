# THE BLOCK — Skills

Reusable agent skills for **THE BLOCK** venue development projects — 165 Randolph
Street and 555 Johnson Avenue, Brooklyn (Live Nation / Insomniac).

Built from the 165 Randolph underwriting and master development budget review,
September 2026.

## Skills

| Skill | Covers |
| --- | --- |
| [venue-buildout-underwriting](venue-buildout-underwriting/SKILL.md) | Tier every budget line 0 / 1 / R / 2, model the shell-and-height decision on its own sheet, and produce a BASE / ELEVATED / PREMIUM ladder with the step-ups priced. Cost-down levers ranked by certainty; phasing premiums per deferred item. |
| [construction-budget-audit](construction-budget-audit/SKILL.md) | The forensic pass: reconcile to source to the dollar, hunt zero-quantity trades, test unit prices against their neighbours, follow the markup cascade, un-stack contingency, reconcile the area basis, read the hidden tabs, find the internal comps. |

Every number carries its estimate class and band. |
| [stage-build-estimating](stage-build-estimating/SKILL.md) | Price a stage from a test fit: what to take off the drawing, a three-tier rate card (countable unit rates, ratios that ride other numbers, capacity bands for use before drawings), the calculation in order, and the per-capacity cross-check that finds the wrong line before the estimate leaves the building. Structure and foundations, lighting per fixture, LED per SF, barricade per LF with corners and freight, containers each. |

| [venue-equipment-sourcing](venue-equipment-sourcing/SKILL.md) | Sound, production, bars (built-in vs container vs modular), kitchen, POS, seating. Build/buy/lease/rent with real payback arithmetic, benchmarked against the operator's own prior builds. |

## The professional-role skills

Three views of the same project, in the order the questions have to be answered:
**is the use permitted** (land use) → **what must be drawn and filed** (architect) →
**who is bound and who bears the risk** (counsel).

| Skill | Covers |
| --- | --- |
| [nyc-architect-compliance](nyc-architect-compliance/SKILL.md) | What the architect of record must establish, draw and file: occupancy classification, Place of Assembly, egress and fixture counts, the DOB filing path for a major alteration, structural and special inspections, FDNY submissions, accessibility. Includes how to test a test fit against the model it justifies. |
| [nyc-land-use-counsel](nyc-land-use-counsel/SKILL.md) | Whether the use is permitted at all: Use Group determination, as-of-right vs special permit, the discretionary approval path and its real timeline, change of use from an existing CofO, community and noise exposure, adjacent lots and development rights. Treats "as-of-right" as a claim to verify, not inherit. |
| [construction-regulatory-counsel](construction-regulatory-counsel/SKILL.md) | Making the compliance position binding and allocating its risk: signing off on the classification, conditions precedent and rent commencement in the lease, who funds and owns permanent improvements, licence sequencing against the programme, construction contract structure. |

## A standing caution

These skills describe process, checklists and what to verify. They are not legal
advice and not a code interpretation. NYC zoning, building code and licensing
change — every regulatory conclusion in a live project needs to come from the
licensed architect and counsel of record, in writing. Where a skill names a
specific requirement it is there to be checked, not relied on.
